# Stitch Image Extractor PRO - Proyecto Completo 📦

Extractor directo, visor de miniaturas y desanidador inteligente para diseños exportados de **Google Stitch AI**.

---

## ⚡ ¿Cómo usarlo en tu computadora?

### En Windows (1 Clic)
1. Haz doble clic en el archivo **`Iniciar_Extractor.bat`**.
2. Se abrirá automáticamente en tu navegador predeterminado (Chrome, Edge, Firefox, Brave).

### En Mac / Linux o cualquier navegador
1. Haz doble clic o abre el archivo **`index.html`** directamente en cualquier navegador web moderno.

---

## ✨ Características Principales
- **Desanidado Recursivo:** Encuentra todas las imágenes (`.png`, `.jpg`, `.webp`, `.svg`, etc.) ocultas en las múltiples subcarpetas de Google Stitch.
- **Galería Visual de Miniaturas:** Previsualiza cada diseño con sus dimensiones exactas (`1920×1080`, etc.) y tamaño de archivo antes de extraer.
- **Protección Anti-Sobrescritura:** Si Stitch genera dos imágenes con el mismo nombre en diferentes carpetas, la app las renombra automáticamente (`diseño_1.png`) para no perder ninguna pantalla.
- **Descarga Selectiva:**
  - Descarga pantallas una a una.
  - Selecciona tus favoritas con casillas de verificación.
  - Guarda sueltas directamente en una carpeta de tu disco.
  - Genera un archivo ZIP 100% plano sin subcarpetas.
- **100% Offline y Seguro:** Todo el procesamiento ocurre en la memoria RAM de tu equipo. Ninguna imagen se transmite a internet.

## 📁 Contenido del Repositorio
- `index.html`: Interfaz gráfica completa de la aplicación.
- `styles.css`: Hoja de estilos con diseño dark glassmorphism.

- `LEEME.txt`: Guía rápida de bienvenida.
- `GUMROAD_LISTING_PACK.md`: Textos persuasivos y ficha para vender en Gumroad.
- `Stitch_Image_Extractor_PRO_v1.0.zip`: Paquete empaquetado para distribución comercial.
